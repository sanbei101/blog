## 工具集成

Agent 通过通用执行环境调用 Bash 或 Python 脚本,已具备广泛的系统交互能力。例如查询外部接口时调用 `curl`,生成结构化报表时生成临时脚本操作 CSV 文件。

但通用 Shell 脚本交互存在显著局限:非结构化的输出会消耗数十倍的会话上下文,且容易引入解析失败或脆弱的命令行拼装。

本章系统梳理适用于研发工作流的高效 MCP 与 CLI 工具体系。通过暴露确定性的结构化接口,替代脆弱的命令行文本抓取,显著提升 Agent 对工程上下文的理解效率与准确率。


## 静态约束

大语言模型在生成代码时具备天然的随机性与懒惰倾向。在缺乏外力约束时,极易产生非规范代码:未检查的返回值、缺乏防御性断言、过度使用弱类型逃避类型推导等。

```go
json.Unmarshal(data, &user) // 忽略了 err 返回值,埋下空指针与解析崩溃隐患

// TypeScript 中使用 any 绕过类型系统
const handleDataSubmit = (event: any) => {
  const payload = (event.target as any).value;
  updateUser(payload);
};
```

在大规模工程中,自动化生成动辄数百行甚至数千行代码,这类局部细节缺陷一旦逃逸到代码库中,会迅速侵蚀系统的架构可读性,增加后续排查与重构成本。

单纯在提示词(如 `AGENTS.md`)中撰写规范文档,会随着会话轮次增加面临注意力稀释问题。

行之有效的工程解法,是将静态代码分析工具链接入协作闭环:

> 在每次任务完成阶段,确保 `make lint` 严格执行并通过。

通过确定性的编译器与静态分析器输出精确报错(如 `errcheck`、`oxlint`),引导 Agent 依据标准行号和错误码实现自主修正。用确定的代码分析规则,收敛概率模型的输出偏差。
